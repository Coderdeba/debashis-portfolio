# Debashis Barmon — Personal Profile Website

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and dynamic footer year

## Run locally
Open `index.html` in a modern browser. Tailwind CSS is loaded from its CDN, so an internet connection is needed for the Tailwind CDN; the custom styling is in `style.css`.

## Publish online
Upload these files to GitHub Pages, Netlify, or Cloudflare Pages. Keep `index.html`, `style.css`, and `script.js` in the same folder.

## Before publishing
Review your phone number and email address. This public portfolio intentionally leaves out sensitive CV details such as national ID number, date of birth, parents' names, religion, blood group, full residential addresses, and referee contact details.
